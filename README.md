# 영상다운로드

더우인(抖音) / 샤오홍슈(小红书) 영상을 URL만 붙여넣으면 워터마크 없이 받는 도구.

- 최대 1080p로 저장 (원본이 더 크면 받은 뒤 1080p로 변환, 최종 파일 하나만 남김)
- 동시에 3개씩 다운로드, 받는 중에도 계속 붙여넣기 가능
- 공유 문구 통째로 붙여넣어도 URL만 골라냄
- 파일명은 붙여넣은 순서대로 `1.mp4`, `2.mp4` ... (사이트별 폴더마다 따로, 빠지는 번호 없이)
- 붙여넣은 링크마다 최종 결과(성공 / 실패 / 건너뜀)를 `목록.txt`에 순서대로 기록 (실행할 때마다 아래에 추가)

  ```
  ===== 2026-10-17 10:39 =====
    1. 성공  douyin\1.mp4   원본 1080p (업스케일 불필요)
       https://www.douyin.com/video/...
    2. 성공  xiaohongshu\1.mp4   원본 2160p (1080p로 줄여서 저장, 업스케일 불필요)
       http://xhslink.com/o/...
    3. 성공  douyin\2.mp4   원본 720p   ★ 업스케일 필요 ★
       https://www.douyin.com/video/...
    4. 실패  샤오홍슈 노트 정보 없음 (...)
       https://www.xiaohongshu.com/explore/...
    5. 건너뜀  이미 받음 -> douyin\1.mp4
       https://www.douyin.com/jingxuan?modal_id=...
    -> ★ 업스케일 필요 ★ (1개, 원본이 1080p 미만): douyin\2.mp4
  ```
- 원본이 1080p 미만인 영상은 `★ 업스케일 필요 ★` 표시 (1080p 이상은 업스케일해도 릴스에서 이득이 거의 없음)
- 실패하면 자동으로 최대 3번 재시도, 끝까지 실패한 건 마지막에 이유와 함께 알려주고 `실패목록.txt`로 저장
- 이미 받은 영상은 건너뜀
- 로그인 필요 없음

## 설치 (새 PC)

1. [Python](https://www.python.org/downloads/) 설치 (설치 시 "Add python.exe to PATH" 체크)
2. Edge 또는 Chrome (윈도우엔 Edge가 기본으로 있음 - 더우인용)
3. 이 저장소 받기

   ```bash
   git clone https://github.com/tjdals423-netizen/downloader.git C:\영상다운로드
   ```

4. `영상다운로드.bat` 더블클릭. 처음 실행할 때 필요한 패키지(requests, playwright, imageio-ffmpeg)를 자동 설치.

## 사용법

- `영상다운로드.bat` 실행 → 링크 붙여넣고 Enter (여러 줄 한꺼번에 OK)
- 빈 줄에서 Enter: 진행 중이면 상황 표시, 다 끝났으면 종료
- 텍스트 파일로 한꺼번에: URL을 적은 .txt 파일을 `영상다운로드.bat` 위에 끌어다 놓기
- 실패한 것 다시 받기: `실패목록.txt`를 `영상다운로드.bat` 위에 끌어다 놓기

받은 파일은 bat 파일이 있는 폴더의 `douyin\`, `xiaohongshu\` 폴더에 저장됨.

## 설정 (`vdl.py` 맨 위)

| 항목 | 기본값 | 설명 |
|---|---|---|
| `MAX_RES` | `1080` | 최대 해상도(짧은 변 기준). `720`이면 더 작게, `None`이면 원본 그대로 |
| `WORKERS` | `3` | 동시에 받을 개수. 너무 늘리면 사이트에서 차단될 수 있음 |
| `RETRIES` | `3` | 실패 시 최대 시도 횟수 |

## 참고

- 사이트 구조가 바뀌면 동작하지 않을 수 있음. 실패한 링크는 마지막에 목록으로 보여줌.
- 더우인 원본이 720p인 영상은 720p로 받아짐 (키워도 화질이 좋아지지 않으므로 그대로 둠).
